# Planificación Urbana CABA

## Descripción

Proyecto de análisis y visualización de datos urbanos de la Ciudad Autónoma
de Buenos Aires.

El proyecto busca estudiar la calidad ambiental de distintas zonas de CABA
a partir de variables como contaminación sonora, flujo vehicular,
arbolado público y espacios verdes.
